### S2-02: `.intro` の html.js ゲート漏れを修正（リデザインで入った退行）

- **対象**: `src/pages/index.astro:670`
- **問題**: ヒーローの文言（キャッチコピー・h1・CTA）の入場アニメ初期状態が **JSゲート無し**で `opacity: 0` になっている:


### S2-03: スプラッシュ画面の JS 無効・ストレージ無効フォールバック

- **対象**: `src/layouts/Base.astro:71-81`（スプラッシュ判定スクリプト）と `:143-146`（`#splash` 本体）
- **問題**: 全画面スプラッシュ `#splash`（`z-index: 9999` の固定要素）の非表示化は「JSが `no-splash` クラスを付ける」「load後に `.done` を付ける」の2経路**のみ**。
  ①JS無効ブラウザでは**全ページが永久にスプラッシュで塞がれ操作不能**。
  ②判定スクリプトの `sessionStorage.getItem('iori-seen')` はストレージ無効環境（一部プライバシーモード）で**例外を投げ**、後続処理に到達せず JS 有効でも①と同じ結末になる。
- **どう変えるか**: 2点セット。

  (a) head 内（`#splash` のCSSより後、`</head>` 手前でよい）に noscript フォールバックを追加:

  ```html
  <noscript><style>#splash { display: none; }</style></noscript>
  ```

  (b) 判定スクリプトの sessionStorage アクセスを try/catch で包む。**失敗時は安全側（スプラッシュを出さない）**:

  ```js
  // 変更前（Base.astro:74-77 付近）
  //   if (sessionStorage.getItem('iori-seen')) { document.documentElement.classList.add('no-splash'); } ...
  // 変更後
  try {
    if (sessionStorage.getItem('iori-seen')) {
      document.documentElement.classList.add('no-splash');
    } else {
      sessionStorage.setItem('iori-seen', '1');
    }
  } catch (e) {
    document.documentElement.classList.add('no-splash');
  }
  ```

  ※現行スクリプトの正確な形（`iori-seen` の set タイミング・load リスナー）は 71-81 行を読み、**既存の分岐構造を保ったまま** try/catch を被せること。上のスケッチはあくまで形の例。
- **完了条件**: ①JS無効でトップを開くとスプラッシュが出ず本文が見える。②JS有効・通常モードで従来どおり「初回のみスプラッシュ→2回目以降スキップ」（タブを開き直すと再表示）。③`npm test` 全パス。
- **リスクと戻し方**: 出力HTMLに `<noscript>` が1要素増える（JS有効時の挙動は不変）。異常時は `git revert`。
- **依存**: S2-00
