## ★ 最重要メタ結論（Codexの横断指摘）

1. **テーマを外して一番事故るのは「色」より「動きの性格」。** 色はズレても補正できるが、動きがテーマと違うと一瞬で違和感（耽美でbounce／癒しで高速reveal／ホラーで強い点滅／サイバーでふわふわ＝即崩壊）。→ **color tokens と同格で motion tokens を持つこと。**
2. **プリセット＝色だけでは世界観を再現できない。** `colors / typography / motion / texture / particles / uiShape` を**1セット**で持つ。
3. **コンポーネントはテーマ名を直接見ない。** すべて CSS変数（`[data-theme]`）越しに切替える。

## ★ 共通スキーマ（テーマ切替のCSS変数設計：Codex案）

```css
/* テーマは [data-theme="cute"] 等でトークンを丸ごと差し替える。
   コンポーネントは下のトークンだけを見る（テーマ名を直接参照しない）。 */
[data-theme]{
  /* 面 */      --bg; --surface; --surface-2;
  /* 文字 */    --text; --muted; --heading;
  /* 主役色 */  --accent; --accent-2; --accent-soft;
  /* 行動 */    --cta; --cta-text;
  /* 線影 */    --line; --shadow;
  /* 書体 */    --font-ja; --font-en;
  /* 動き */    --motion-duration; --motion-ease; --motion-distance; --motion-scale;
  /* 粒子 */    --particle-color; --particle-opacity; --particle-density;
  /* 質感 */    --texture-url; --texture-opacity;
}
/* 例：コンポーネントは抽象トークンだけ参照 */
.btn   { background:var(--cta); color:var(--cta-text); transition:var(--motion-duration) var(--motion-ease); }
.card  { background:var(--surface); border-color:var(--line); box-shadow:var(--shadow); }
.heading{ color:var(--heading); font-family:var(--font-ja); }
/* particle/canvas 初期化は --particle-* を読む */

/* 全テーマ共通の安全弁 */
@media (prefers-reduced-motion: reduce){
  .particle, canvas.fx{ display:none; }      /* 粒子は消すか静止 */
  .reveal{ transform:none !important; }        /* revealはopacityのみ */
  .shimmer,.glitch,.flicker{ animation:none !important; }
}
.particle,.fx-layer{ pointer-events:none; }
```

**motion トークンのテーマ別傾向（Codex）**
| テーマ | duration | ease | distance/scale |
|---|---|---|---|
| 耽美・ゴシック | 長め(400〜800ms) | 重い ease-out `cubic-bezier(.22,1,.36,1)` | 小・bounce禁止 |
| かわいい・ポップ | 短め(150〜300ms) | overshoot `cubic-bezier(.34,1.56,.64,1)` | scale 1.02・弾む |
| クール・サイバー | 短め | sharp `cubic-bezier(.2,.8,.2,1)`/`steps()` | 直線・glitchは一瞬 |
| 和風・和モダン | 長め | ease-in-out `cubic-bezier(.37,0,.63,1)` | 小・横流れ/余韻 |
| ファンタジー・幻想 | 長め | ease-in-out・浮遊 | 小・parallax少量 |
| ナチュラル・癒し | とても長い(4〜6s呼吸) | ease-in-out | 極小・soft lift |
| ホラー・ダーク | 短いが**低頻度** | 微ズレ・浅いflicker | 1px・**点滅禁止寄り** |
| ゲーマー | 短い(hover120〜200ms) | sharp・反応速い | カチッと浮く |

## テーマ別プリセット（8種）

各テーマ＝1行サマリ／配色（トークン対応hex・当たり値）／フォント／降りもの／文字装飾／背景・質感／ホバーUI／地雷。

### 1. 耽美・ゴシック（黒×金/ダークエレガント）★和香松庵の正トーン
- **核**：漆黒の余白にくすみ金が一点で灯る「沈黙と高級感」。引き算の美学。執事/Bar/吸血鬼/退廃ロマン・ASMR向け。
- **配色**：`--bg #0B0A0D` ／ `--surface #17131A`(焦茶黒) ／ `--text #E8E2D6`(骨色) ／ `--accent #C9A227`(くすみ金) ／ `--cta #E6C566`＋`--cta-text #1A1410` ／ `--accent-2 #8B1E3F`(ボルドー)。**金は線/小見出し/装飾に限定、本文は骨色**（金本文は読めない）。
- **フォント**：日本語＝黒華明朝/源暎こぶり明朝/しっぽり明朝（本文はNoto Serif JPかゴシック）。欧文＝Cinzel・Cormorant Garamond・Playfair Display。字間広め。
- **降りもの**：低密度の金粉・黒羽根・薄い燭光ノイズ（Canvas少量／10〜20粒）。→#3参照。
- **文字装飾**：金の細線罫・ドロップキャップ・額縁見出し・極薄の金グロー（やりすぎ厳禁）。
- **背景**：漆黒＋極薄フィルムグレイン＋ヴィネット＋ダマスク/唐草を opacity 3〜6%。
- **ホバーUI**：金罫がすっと伸びる・カード1〜2px浮き・色反転しない。
- **地雷**：純黒#000＋ギラ金＝パチンコ感／金を本文に／花びら吹雪・glow過多／角丸ポップUI／赤の多用。

### 2. かわいい・ポップ（パステル/アイドル/ゆめかわ）
- **核**：高明度・低彩度パステル＋丸み＋軽快に弾む動きで「会いに行ける」親しみ。歌/アイドル/元気系/参加型向け。
- **配色**：`--bg #FFF5FA`(桜白)/`#F2E2FF`(薄紫) ／ `--surface #FFFFFF` ／ `--text #5A4A55`(焦げ茶ぶどう) ／ `--accent #F075AB` ／ `--cta #E85C92`＋`--cta-text #FFFFFF`(淡ピンクCTAは白文字でAA割れ→濃いめに) ／ 差し色 `#8FD8FF`(ミント)/`#FFE36E`(パステル黄・文字は焦茶)。
- **フォント**：日本語＝丸ゴシック（Zen Maru Gothic/コーポレートロゴ ラウンド/Rounded Mplus、本文Noto Sans JP）。欧文＝Quicksand/Baloo 2/Fredoka/Nunito。手書きはワンポイント。
- **降りもの**：ハート・星・シャボン玉・紙吹雪（純CSS、耽美より多めOKだがモバイル間引き）。クリックでハート弾けるマイクロインタラクション◎。
- **文字装飾**：白フチ取り（text-stroke/多重shadow）でステッカー感・淡ピンクのマーカー・パステルグラデ文字。
- **背景**：パステルグラデ・水玉/チェック（低彩度）・ぼかしブロブ・小さな星ドット。
- **ホバーUI**：pill型ボタンが浮く＋プチ拡大・影が明るく。
- **地雷**：彩度上げすぎ＝駄菓子感／色数入れすぎ＝幼稚／淡ピンク文字 on 白＝読めない／明朝・黒ベタ＝不一致。

### 3. クール・サイバー（ネオン/未来/テック）
- **核**：ほぼ真っ黒な夜景にネオン1〜2色を「信号」として点す。色を増やすほど安くなる。SF/メカ/技術解説向け。
- **配色**：`--bg #08111F`(深紺黒) ／ `--surface #101B2E` ／ `--text #D6F7FB`(薄シアン白・**純白は使わない**) ／ `--accent #05D9E8`(シアン) ／ `--accent-2 #FF2A6D`(ホットピンク) ／ `--cta #FCEE0A`(ネオン黄・行動に集中投下) ／ 装飾 `#7700A6`。**信号色は主役1＋副1まで**。
- **フォント**：欧文＝Orbitron(ロゴ)/Rajdhani(UI)/Share Tech Mono・Space Mono(計器)。日本語＝角ゴ（Noto Sans JP Bold/M PLUS 1 Code）。明朝は避ける。
- **降りもの**：データ粒子（縦流れ）・光跡・三角格子明滅・スキャンライン（純CSS `repeating-linear-gradient`/`conic-gradient`、大量はCanvas）。
- **文字装飾**：ネオングロー（`text-shadow`多段＋**芯はベタ色で確保**）・グリッチ（`clip-path`色ズレ・ホバー/初回のみ）・等幅ラベル。
- **背景**：パース床グリッド・スキャンライン（微フリッカー）・メッシュ/コニックグラデ・回路パターン。
- **ホバーUI**：HUD/ターミナル風（角ブラケット発光）・`>_`プロンプト・走査線ボタン。
- **地雷**：ネオン3色以上全面＝目が痛い／芯色なしグロー文字＝読めない／常時激しい明滅＝**WCAG2.3.1違反**。glowループは`box-shadow`でなく`opacity`/`filter:drop-shadow`で。

### 4. 和風・和モダン（巫女/妖/伝統）
- **核**：生成り和紙地に朱と金を線・点・縁で効かせる。余白と「間」で見せる。巫女/妖怪/花魁/雅楽・大人静的配信向け。
- **配色**：`--bg #FAF7EF`(生成り)/墨地 `#1A1A1A`(アクセント面) ／ `--text #2C2C2C`(墨) ／ `--accent #C73E3A`〜真朱`#8F1D21` ／ `--accent-2 #1F4E8C`(藍) ／ `--cta #C9A227`〜`#D4AF37`(金茶)。金は見出し大/装飾/縁限定、本文は墨。
- **フォント**：日本語＝黒華明朝/源暎こぶり明朝/しっぽり明朝（本文Noto Serif JP）。欧文＝Cinzel・EB Garamond（**欧文は主張させない**）。
- **降りもの**：桜・紅葉・粉雪・金粉・紙片・蛍（純CSS 1〜2層・季節差し替え）。→#3参照。
- **文字装飾**：縦書き（`writing-mode`）・落款（朱の角印SVG 1点）・金箔グラデ文字・飾り罫。
- **背景**：青海波/麻の葉をSVGタイルで opacity 0.04〜0.08・和紙テクスチャ・墨にじみ。
- **ホバーUI**：朱線がすっと引かれる・和紙カードが少し浮く。
- **地雷**：原色赤＋黒＋金ベタ＝旅館/居酒屋・チープ和風／和柄全面ベタ＝うるさい／明朝細すぎ＝モバイルでかすれ。

### 5. ファンタジー・幻想（魔法/ドリーミー/星空）
- **核**：深い藍紫のナイトベースに紫・銀・星明かりの金。落下より「漂う/明滅」。魔女/RPG/占い/ドリーミー歌姫向け。
- **配色**：`--bg #13072F`〜`#0E1A3A`(深藍紫) ／ `--text #E6E3F0`(月光シルバー) ／ `--accent #6554FB`〜`#7C5CFF`(ルーン紫) ／ `--accent-2 #F6A6FF`/`#8BE7D1` ／ `--cta #E8C766`〜`#F2D680`(星明かりの金)。淡ラベンダーは大見出し限定。
- **フォント**：日本語＝端正な明朝（Noto Serif JP/しっぽり明朝）＋上品な丸ゴ。欧文＝Cinzel/Cinzel Decorative・Cormorant Garamond・EB Garamond・Spectral（写本感は1点だけ）。
- **降りもの**：星屑・光の粉・魔法粒子・蛍（純CSS twinkle＋Canvas低密度）。グローは控えめ。
- **文字装飾**：魔法陣SVG（同心円＋ルーン）を背後に極薄・超低速回転 or 静止／淡いグロー1段／金銀グラデ文字。
- **背景**：星空（多層radial）・オーロラ（gradientゆっくり移動）・ネビュラ（ぼかしブロブ）・ヴィネット。
- **ホバーUI**：発光が強まる・紫→金グラデ移動・半透明ガラス縁発光（控えめ）。
- **地雷**：原色ネオン盛りすぎ＝中二崩れ（アクセント1色に絞る）／グロー多重でにじむ／粒子増やしすぎ／宇宙ストック画像＝既視感。

### 6. ナチュラル・癒し（ほっこり/ASMR/lo-fi）
- **核**：生成り紙地に木漏れ日、葉やぽわぽわがゆっくり漂う「呼吸する速度」。ASMR/雑談/作業lo-fi/カフェ/睡眠導入向け。
- **配色**：`--bg #FAF7F0`/`#F7F3EA` ／ `--text #4A3F35`(焦茶・約8:1) ／ `--accent #7C9473`/`#6F8F72`(セージ) ／ `--surface-2 #E4CBA8`(暖砂) ／ `--cta #C2855B`(テラコッタ)＋`--cta-text #FFFDF8`(大きいボタン前提でAA) ／ 装飾 `#D6B2C2`(ダスティローズ)。本文は必ず焦茶。
- **フォント**：日本語＝丸ゴ/やわらかゴシック（Zen Maru Gothic/とよまーる・本文Zen Kaku Gothic New/Noto Sans JP）。欧文＝Quicksand/Nunito/Comfortaa/Lora。手書きはひとさじ。
- **降りもの**：木漏れ日（`radial-gradient`＋`mix-blend-mode:soft-light`ゆらぎ）・落ち葉5〜10枚・湯気/ぽわぽわ。基本は静的でも可。
- **文字装飾**：やわらか下線（gradientマーカー）・葉アイコン・強調は「太さ・余白」で。
- **背景**：和紙/紙（淡グラデ＋SVGグレイン opacity 0.03〜0.06・静止）・布/木目・lo-fiノイズ。
- **ホバーUI**：`translateY(-2px)`＋温色のやわらか影・角丸大きめ。
- **地雷**：全部くすみ＋全部丸＝メリハリ消失（焦茶テキスト＋テラコッタで締める）／くすみ色を本文に＝AA割れ／手書き本文＝読めない／長周期×多数同時＝酔い。

### 7. ホラー・ヤンデレ・ダーク
> **安全宣言：画面を点滅・フラッシュさせない（WCAG2.3.1厳守）。怖さは点滅でなく「暗さ・にじみ・静寂・じわっとした動き」で作る。**
- **核**：暗闇＋ビネット＋微粒子の中、にじむ明朝が静かに不穏を語る。ホラゲ実況/怪談/ヤンデレASMR/オカルト向け。
- **配色**：`--bg #0B0A0C`(漆黒寄り) ／ `--text #C9C4C0`(くすみ灰白・約11:1・**純白は避ける**) ／ `--accent #8A1C1C`(くすみ血赤) ／ `--cta #B22222`＋`--cta-text #F2E9E9` ／ 装飾 `#3A2A33`(暗紫赤)。**血赤を本文色にしない**。
- **フォント**：日本語見出し＝おそろしげ明朝/07ふぉんとうは怖い明朝体（**短文限定**）・血文字風は1単語だけ。本文＝普通の明朝（Noto Serif JP等・**装飾フォント本文厳禁**）。欧文＝細セリフ/condensed。
- **降りもの**：灰・塵・赤い微粒子・薄い影・雨（低密度）。血滴は避ける/限定（緩やかな滴下のみ）。
- **文字装飾**：にじみ（暗赤text-shadow薄く多重）・かすれ・破れ紙・伏せ字風ラベル・グリッチ（位置ズレのみ・**輝度大振幅にしない**・低頻度）。
- **背景**：フィルムノイズ・暗い紙・薄い傷・ビネット（中央集中）・暗紫赤グラデ。
- **ホバーUI**：文字が1pxずれる・赤線がにじみ出る・影が伸びる（transitionでゆっくり）。
- **地雷**：**点滅/激しいグリッチ＝WCAG違反＆発作リスク**（最大）／グロ過剰＝閲覧注意化／装飾フォント本文・暗赤本文＝読めない／自動再生音は不可。

### 8. ゲーマー・ストリーマー（RGB/eスポーツ）
- **核**：暗ベース＋高彩度アクセントで「速読・即視認」。配信オーバーレイ的ハイテンション。ゲーム配信/参加型/コラボ・大会向け。
- **配色**：`--bg #0B1020`/`#0D0D12` ／ `--surface #141B2D` ／ `--text #E6E8FF`(薄青白) ／ `--accent #9146FF`(Twitch紫・記号性) ／ `--accent-2 #00E5FF`(シアン)/`#FF3D8B` ／ `--cta #7CFF4F`/`#A2FF1A`(ネオンライム・紫背景に最映え)。暗ベース＋高コントラストCTA集中。
- **フォント**：欧文＝Orbitron/Rajdhani/Barlow Condensed・Share Tech Mono(スコア)。日本語＝太角ゴ（Noto Sans JP Black/Mochiy Pop）。明朝・細字は避ける。
- **降りもの**：RGB光跡・スパーク（投げ銭/フォロー演出）・HUDドット・スキャンライン（純CSS `conic-gradient`＋`hue-rotate`が軽量／祝祭多発はCanvas）。
- **文字装飾**：HUD風ラベル・枠線・ステータス/ライブ小バッジ・RGBグラデ文字（芯色確保）。
- **背景**：ダークパネル・グリッド・斜めライン・発光ボーダー（RGB循環）。
- **ホバーUI**：ボタン発光・角が走る・カードがカチッと浮く・配信通知風ポップ。
- **地雷**：RGB全面同時循環＝安いゲーミング機器感・視線が定まらない（循環は枠/差し色に限定）／低コントラスト本文／点滅乱発＝WCAG2.3.1違反。色循環は「明滅」でなく「滑らかな推移」に。

## 実装優先順位（Codex推奨）
1. **第1段（需要広・差が出る）**：かわいい・ポップ → クール・サイバー → ナチュラル・癒し → 耽美・ゴシック
2. **第2段（刺さるが地雷多い）**：ホラー → 和風 → ファンタジー → ゲーマー

> ツールの作り：本人には「かわいい/サイバー/和風…」と**名前で選ばせ**、内部は `[data-theme]` のCSS変数＋motion設定を**丸ごと切替**。各テーマは `colors / typography / motion / texture / particles / uiShape` の6点セットで定義する。

## 全テーマ共通の安全弁（再掲）
- 動かすのは `transform`/`opacity`（＋必要時`filter:drop-shadow`）のみ。`box-shadow`/`background-position` のループは避ける。
- `prefers-reduced-motion: reduce`：粒子は display:none/静止・revealはopacityのみ・hoverは色変化だけ・shimmer/glitch/flicker停止。
- WCAG：点滅1秒3回未満（特にサイバー/ゲーマー/ホラー）・本文コントラスト4.5:1以上（装飾色を本文に流用しない）・ホバーは `@media (hover:hover)`。
- 粒子はモバイルで自動間引き（density変数）。Canvasは DPR上限1.5〜2・IO画面外停止。
